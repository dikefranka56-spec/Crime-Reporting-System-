# FPNO Anonymous Crime Reporting System

A secure anonymous crime reporting system built for Federal Polytechnic Nekede Owerri to allow students report crimes without fear of being exposed.

Built by Dike Frankjacob Chizurumoke - HND Computer Science, FPNO 2026.

## Problem
Students in FPNO are afraid to report theft, cultism, harassment because of fear. This platform solves it by giving 100% anonymous reporting with tracking ID.

## Features

**Students can:**
- Report crime anonymously (No login needed)
- Choose crime type - Theft, Cultism, Harassment, Assault, Fraud
- Select location - E-Block, SUG, School Gate, Hostel
- Get Tracking ID to check status later
- Upload description and date of incident

**Security Admin can:**
- View all reports on dashboard
- Update status to Pending, Investigating, Resolved, Dismissed
- Add officer remarks
- See total reports

## Tech Stack
Frontend: React.js, Tailwind CSS
Backend: Node.js, Express.js
Database: MongoDB
Auth: JWT

## How to Run

Backend:
cd server
npm install
npm start

Frontend:
cd client
npm install
npm run dev
